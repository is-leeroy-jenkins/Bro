# Configuration API

Configuration values are defined in `config.py` and consumed by the Streamlit application.

Important runtime values include:

- `MODEL_PATH`
- `DEFAULT_CTX`
- `CORES`
- `DB_PATH`
- `FAVICON`
- `LOGO`
- `APP_SUBTITLE`
- `MODES`
- `BLUE_DIVIDER`
- `XML_BLOCK_PATTERN`

Bro also recognizes optional multimodal-projector configuration through `MMPROJ_PATH` or
`MM_PROJ_PATH` when present.
