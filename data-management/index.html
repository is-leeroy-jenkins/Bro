    Data Management¶

    Data Management provides local SQLite administration, import, browsing, profiling, filtering, aggregation, visualization, guarded SQL, and AI asset governance tools.

    🧭 Purpose¶

    This mode gives Bro a local data layer that supports both general tabular workflows and AI-specific asset tracking. It allows analysts to inspect application tables, work with imported data, and register document, chunk, embedding, and image metadata generated by other modes.

    🧱 Workflow Position¶

    Local files and runtime assets
  ▼
SQLite database
  ▼
Browse, CRUD, profile, filter, aggregate, visualize
  ▼
AI asset governance tables
  ▼
Document Q&A and Semantic Search support

    🗄 SQLite Role¶

    The local database stores operational state and AI assets.

    Table Area Description
    Chat history Role/content messages used by Text Generation.
    Prompts Reusable prompt templates and prompt metadata.
    Embeddings Semantic Search chunk vectors.
    Documents Registered document metadata.
    Document chunks Registered chunk metadata and chunk text.
    Document embeddings Registered embedding metadata.
    Images Uploaded image metadata.

    📥 Import¶

    The import workflow brings external tabular data into SQLite.

    Capability Description
    Excel import Imports workbook data into database tables.
    Table creation Creates tables based on dataframe columns.
    Data insertion Inserts dataframe rows into selected tables.
    Asset registration Registers active documents, chunks, embeddings, and images when enabled.

    🗂 Browse¶

    Browse mode displays table content from the local SQLite database.

    Control Use
    Table selector Chooses the table to inspect.
    Limit Restricts returned rows for performance.
    Offset Pages through larger tables.
    Schema view Displays column metadata.

    💉 CRUD¶

    CRUD operations support basic row-level table management.

    Operation Use
    Create Insert new records.
    Read Inspect selected rows.
    Update Modify existing values.
    Delete Remove selected rows.

    Use CRUD carefully on application tables because prompt, chat, embedding, and document workflows depend on stable schemas.

    📊 Profiling and Exploration¶

    Data profiling summarizes table columns.

    Metric Meaning
    Data type Pandas dtype inferred from the loaded table.
    Null percent Percentage of rows with missing values.
    Distinct percent Percentage of distinct values.
    Minimum Minimum value for numeric columns.
    Maximum Maximum value for numeric columns.
    Mean Mean value for numeric columns.

    🔎 Filtering¶

    Filtering supports quick table narrowing by column, operator, and value.

    Operator Behavior
    = Exact equality.
    != Inequality.
    > Numeric greater-than comparison.
    < Numeric less-than comparison.
    >= Numeric greater-than-or-equal comparison.
    <= Numeric less-than-or-equal comparison.
    contains Text substring match.

    🧮 Aggregation¶

    Aggregation computes summary metrics over numeric columns.

    Aggregation Result
    COUNT Number of non-null values.
    SUM Total.
    AVG Mean.
    MIN Minimum.
    MAX Maximum.
    MEDIAN Median.

    📈 Visualization¶

    Visualization uses Plotly to render exploratory charts.

    Chart Typical Use
    Histogram Distribution of numeric values.
    Bar Compare categories or grouped values.
    Line Show ordered or time-like trends.
    Scatter Compare two numeric fields.
    Box Review spread and outliers.
    Pie Display category share.
    Correlation Inspect numeric relationships.

    🧷 Schema Administration¶

    Schema tools include table, column, and index operations.

    Operation Description
    List tables Displays SQLite tables.
    Create schema view Shows column definitions.
    Create custom table Builds a validated table from column definitions.
    Add column Adds a sanitized column to an existing table.
    Drop column Rebuilds a table without the selected column when needed.
    Rename table Uses native rename or safe rebuild fallback.
    Rename column Uses native rename or safe rebuild fallback.
    Create index Builds a validated index on a selected table column.

    🛡 Guarded SQL¶

    The SQL console is designed for read-only workflows.

    Allowed starts:

    SELECT
WITH
EXPLAIN
PRAGMA

    Blocked operations include:

    INSERT
UPDATE
DELETE
DROP
ALTER
CREATE
ATTACH
DETACH
VACUUM
REPLACE
TRIGGER

    This guard protects local application state from accidental destructive SQL execution.

    🧯 Failure Handling¶

    Data Management operations interact with SQLite, pandas, and user-supplied table names. Exceptions should be logged with stable function signatures. Logged method strings should not include SQL text, dataframe contents, file contents, or user-entered values.

    ✅ Recommended Sequence¶

    1. Inspect available tables.
    2. Review schema before editing.
    3. Use browse or read-only SQL for exploration.
    4. Profile columns before transformation or visualization.
    5. Use CRUD only when the table purpose is clear.
    6. Register AI assets after active documents are loaded and reviewed.
    7. Run a backup before destructive schema administration.
